# Genbeya
Genbeya joins two words from lean manufacturing:
- genba (現場, "the real place", where value is actually created; lean's advice is to go to the genba instead of reading reports elsewhere)
- obeya (大部屋, "big room", the project room where plans, tasks, problems and status hang on the walls for everyone to see).

Genbeya is the big room at the real place: everything about a project — docs, tasks, decisions, code and history — kept right where the work happens, in the repository: versioned, reviewable, and available to every tool and person that can read files.

It is pronounced "gen-BEH-ya".
